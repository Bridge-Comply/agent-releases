# Bridge Comply agent downloads

Signed installer releases for Bridge Comply customers. Downloads do not require a GitHub account.

Each release includes the macOS installer, its SHA-256 checksum and a build provenance record. macOS packages are signed by BRIDGE COMPLY LTD (Apple Team ID 72RPH63P5M), notarised by Apple and stapled before publication.

Install the package, approve the Bridge Comply system extension and content filter when macOS asks, then open the Endpoint agent section of your Bridge Comply Integrations page to enrol the device. Blocking requires enrolment, approved permissions and your organisation's signed policy.

Check the downloaded package against its published checksum before installation. Published versions are immutable. Corrections use a new version.

Linux and Windows installers are not included in the current customer release. Agent source and signing credentials are maintained separately.

For support, contact support@bridgecomply.com.
